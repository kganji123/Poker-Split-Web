OPTION 1: GitHub Pages (Recommended - Free & Fast)
───────────────────────────────────────────────────

Step 1: Upload to GitHub
  1. Go to: https://github.com/Kganji123/poker-split-web
  2. Click "Add file" → "Upload files"
  3. Drag & drop all 6 files (5 HTML + README.md)
  4. Commit message: "Deploy PokerSplit v1.0"
  5. Click "Commit changes"

Step 2: Enable GitHub Pages
  1. Go to: Settings → Pages
  2. Source: Deploy from branch
  3. Branch: main
  4. Folder: / (root)
  5. Click "Save"

Step 3: Wait & Visit
  ⏱️  Wait 60-90 seconds for deployment
  🌐 Live at: https://kganji123.github.io/poker-split-web

Step 4: Custom Domain (Optional)
  1. Same Settings → Pages screen
  2. Custom domain: pokersplit.com
  3. ✓ Enforce HTTPS
  4. Save
  5. Wait 5-10 minutes for SSL certificate

All data stored in browser localStorage:
  Key: pokersplit_league_v1

Export/Backup:
  Open browser console (F12)
  Run: localStorage.getItem('pokersplit_league_v1')
  Copy the output and save it

Import/Restore:
  Open browser console (F12)
  Run: localStorage.setItem('pokersplit_league_v1', 'YOUR_BACKUP_JSON')
  Reload page

Site not loading after GitHub Pages enable:
  - Wait full 2 minutes (can take up to 5 min)
  - Check Settings → Pages shows green checkmark
  - Try incognito/private window

Pages look different:
  - Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
  - Clear browser cache

Navigation not working:
  - Make sure all 5 HTML files uploaded to root (not subfolder)
  - Check file names are lowercase exactly as shown

Mobile issues:
  - Designed for max-width 440px
  - Works best in portrait mode
  - "Add to Home Screen" for app-like experience

Data lost:
  - localStorage is per-domain
  - If domain changes, data stays on old domain
  - Export/backup data before domain changes
